# Sample datasets (SYNTHETIC)

Every file in this directory is **synthetic demonstration data**, generated by
`data/generate_samples.py` (and by `backend/database/seed.py` when the database is
empty). None of it represents a real company, real products, real sales or real
suppliers. All company names use the reserved `.example` domain.

| File | Description |
| --- | --- |
| `sales_history.csv` | Daily units sold per product per warehouse, with selling price. This is the CSV format the dashboard upload accepts. |
| `inventory_snapshot.csv` | Current stock, reserved stock, incoming stock and capacity per product/warehouse. Used to seed the `inventory` table. |
| `supplier_offers.csv` | Supplier master data joined with per-product commercial terms (price, lead time, reliability, MOQ). |

## Regenerating

```bash
python data/generate_samples.py --days 180 --end 2026-10-31
```

## What the synthetic data contains

* 3 warehouses (Central / North / South), 8 products (P001–P008), 5 suppliers
  (one deliberately `suspended` so constraint handling is demonstrable).
* 180 days of daily sales with a weekly cycle, mild trend, monthly ripple and
  seeded noise.
* A built-in demonstration situation: **P001 demand rises ~35 % in W1 during the
  last 30 days while W1 holds only 45 units** of stock. W2 and W3 hold the surplus,
  so the workflow must transfer rather than only buy.

## Upload format

Required columns: `date, product_id, product_name, warehouse_id, units_sold, selling_price`.

```csv
date,product_id,product_name,warehouse_id,units_sold,selling_price
2026-01-01,P001,Industrial Bearing 6204,W1,42,6.50
```

Validation rejects: missing mandatory columns, invalid dates, non-numeric or
negative `units_sold`, non-positive `selling_price`, blank keys, and de-duplicates
repeated `(date, product_id, warehouse_id)` rows (latest wins).
